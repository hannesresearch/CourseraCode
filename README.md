# IBM Data Science Capstone Project

This repository contains the capstone project completed as part of the IBM Data Science Professional Certificate on Coursera.

The project investigates the relationship between SpaceX Falcon 9 first-stage landing outcomes and various launch-related factors. It follows an end-to-end data science workflow, covering data collection, data wrangling, exploratory data analysis, visualization, and machine learning.

## Methods and Tools

- Python: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- Data collection and processing using APIs and web scraping
- Exploratory data analysis and data visualization
- SQL-based data analysis
- Classification models and model evaluation
- Interactive dashboard development using Plotly Dash

## Project Structure

The notebooks are organized according to the main stages of the project:

1./2. Data collection
3. Data wrangling
4. Data visualization
5. Exploratory data analysis
6. Interactive dashboard
7. Predictive modelling


**Note:** This project was completed as a guided capstone assignment within the IBM Data Science Professional Certificate. It demonstrates practical application of the methods and tools covered in the course.
